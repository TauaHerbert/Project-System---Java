# 🖥️ Project System

Sistema desktop desenvolvido em Java com interface gráfica (Java Swing) e integração com banco de dados.

## 📌 Sobre o Projeto

O Project System é um sistema de gerenciamento desenvolvido com o objetivo de praticar conceitos de:

- Programação Orientada a Objetos
- Java Swing (Interface Gráfica)
- Integração com Banco de Dados
- Manipulação de valores monetários com BigDecimal
- Estruturação de CRUD (Create, Read, Update, Delete)

## 🚀 Funcionalidades

- ✅ Cadastro de Produtos
- ✅ Listagem de Produtos em JTable
- ✅ Seleção de Categorias com JComboBox
- ✅ Integração com Banco de Dados
- ✅ Estrutura preparada para múltiplas formas de pagamento

## 🛠️ Tecnologias Utilizadas

- Java
- Java Swing
- JDBC
- Banco de Dados (MySQL)

## 🗄️ Estrutura do Banco (Resumo)

- Tabela `cliente`
- Tabela `endereco`
- Tabela `produto`
- Tabela `pedido`
- Tabela `categoria`
- Tabela `item_pedido`
- Tabela `forma_pagamento`
- Tabela `pedido_pagamento`

## 🎯 Objetivo do Projeto

Projeto desenvolvido para fins acadêmicos e aprimoramento das habilidades em desenvolvimento de sistemas desktop utilizando Java.
